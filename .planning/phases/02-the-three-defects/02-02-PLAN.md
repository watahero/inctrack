<objective>
Kill the third defect: a window that asks ImGui for a close control it can never
draw, and an addon shell that waits for a click on it.

Purpose: it is dead code that reads as a feature. `docs/design.md` describes a
title-bar close button driving visibility; the window has been created with no
title bar since 1.1.0, so the box handed to `Begin` is never written to and the
branch that reads it is unreachable. Nothing in game changes -- which is the
point. The window already auto-hides thirty seconds after a run ends, and
`/incursion` is the manual dismiss the README documents.

Output: `inctrack/ui.lua` and `inctrack/inctrack.lua` with the plumbing gone;
the six render snapshots re-pasted to match the recorded call shape; FIX-03
converted from an expected failure to an ordinary passing check with its Phase-1
text intact; the known-defect count and set taken to zero; and the phase's
in-game check recorded.
