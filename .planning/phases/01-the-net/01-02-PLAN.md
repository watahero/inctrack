## Hard rules for this plan

1. **Do not edit anything under `inctrack/`.** If a helper is unreachable,
   reach it with `lua_locals`, not by exporting it from the addon.
2. **Every assertion except the single FIX-03 xfail must be true against the
   code as it ships today.** If a check you write goes red, it is either wrong
   or you have found a fourth defect — stop and report it. Do not add it, and
   do not turn it into a second xfail: the phase closes on exactly three.
3. **No assertion may depend on a choice Phase 2 is free to make.** FIX-03 can
   be fixed either by deleting the close plumbing or by dropping the
   no-title-bar flag. Nothing in this suite may assert that the flag is present.
4. The suite reads no files and takes no chatlogs (D-12). Fixtures are inline
   chat strings, using invented content names in the established style.
5. Suite title string must begin with `ui: ` so the report line is greppable.
